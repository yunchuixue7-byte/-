## 实验1：课程基础与实验环境搭建（编号 1，2026年9月20日）
目的：熟悉工具链，理解实验体系与软件工程流程。
任务：① 安装配置编程工具、Git、IDE、建模工具；② 注册 GitHub 账号、创建实验仓库；③ 编写 Hello World 并提交；④ 阅读课程第一章、自主选题；⑤ 撰写初步实验计划。
要求：工具能正常运行，仓库提交记录完整；实验计划包含个人学习目标与时间分配。

## 实验2：需求分析（编号 2，9月22日 / 9月29日 / 10月13日）
目的：掌握需求获取方法，学会定义需求、描述需求。
任务：① 基于实验1 选题收集需求；② 用"问卷 + 访谈"模拟需求调研，整理功能性与非功能性需求清单；③ 撰写《需求规格说明书》。
要求：需求清单无歧义、可验证；说明书结构完整（参考课程模板）。

## 实验3：UML 建模（编号 3，10月20日）
目的：掌握面向对象设计，学会使用 UML 建模。
任务：① 下载常用 UML 建模软件并学会使用；② 基于实验2 的需求分析，用**用例图**描述需求；③ 针对核心模块给出**用例描述**；④ 绘制 **2 个用例图**（含参与者、用例、关系）。
要求：熟悉 UML 建模经典方法；会使用建模软件；用例图符合 UML 规范、覆盖核心业务。
**注意：本实验只考用例图与用例描述，不要求类图、时序图（那是实验4、实验5 的内容）。**

## 实验4：系统概要设计（编号 4，10月27日）
目的：掌握架构设计与模块划分方法。
任务：① 基于实验2 需求设计系统架构（推荐 MVC / 三层架构）；② 划分核心模块；③ 绘制系统结构图、模块依赖图；④ 定义模块间接口（输入/输出、功能描述）。
要求：架构符合需求，模块划分高内聚低耦合；接口定义清晰，无冗余依赖。

## 实验5：系统详细设计（编号 5，11月3日）
目的：掌握具体的设计与流程设计，实现概要设计。
任务：① 对核心模块设计**类图**（类、属性、方法、关系：继承/关联/聚合）；② 绘制关键业务**时序图**（例如"图书借阅"流程，本课程设计对应"落子/AI 应答"等流程）；③ 设计数据库 E-R 图等结构（至少 2 张表，考虑主键、外键、约束）。
要求：类图无逻辑错误，时序图覆盖完整流程；E-R 图符合第三范式，有基本流程图。

## 实验6：编码规范与模块化编程（编号 6，11月10日）
目的：遵循编码标准，实现模块化开发。
任务：① 学习 Java/Python 等编码规范（命名、注释、格式）；② 基于实验5 的设计编写核心模块代码（聚焦 1 个模块，附上核心代码）；③ 实现模块间接口调用；④ 提交代码至 Git 仓库并写 README。
要求：代码符合规范、无语法错误；模块独立可单独编译运行；commit 信息清晰。

## 实验7：版本控制与团队协作（编号 7，11月17日，文中标为"实验8"）
目的：掌握 Git 核心操作，模拟团队协作流程。
任务：① 分组（2-3 人/组）创建团队仓库，设置分支策略（master/dev/feature）；② 每人基于 feature 分支开发不同模块并推送；③ 完成分支合并、解决简单冲突；④ 编写团队协作规范。
要求：分支操作正确、冲突解决合理；仓库有完整分支历史与协作记录。

## 实验8：单元测试（编号 8，11月24日，文中标为"实验9"）
目的：掌握单元测试方法，理解测试驱动开发思想。
任务：① 为实验6 的核心代码编写单元测试用例（覆盖正常/异常，语句覆盖率较高）；② 尝试 TDD；③ 运行测试并生成测试报告；④ 修复发现的 bug。
要求：用例设计合理、覆盖率达标；报告包含结果分析与 bug 修复。
现状：本项目已有 43 个 xUnit 单元测试（全绿），可直接作为素材。

## 实验9：集成测试（编号 9，12月1日，文中标为"实验10"）
目的：掌握集成测试流程，学会缺陷跟踪。
任务：① 对已开发模块做集成测试，设计聚焦接口交互的用例；② 使用工具测试接口（若有 Web 模块）；③ 模拟缺陷提交：用 GitHub Issues 记录缺陷（复现步骤、预期结果、实际结果）；④ 描述集成测试结果。
要求：用例设计合理、覆盖率达标；报告包含结果分析与 bug 修复。

## 实验10：综合项目实战（编号 10，12月8日，文中标为"实验11"）
目的：整合软件工程完整流程，完成小型软件系统落地。
任务：① 基于前 10 个实验完成"XXX 系统"核心功能开发；② 流程：需求细化→设计优化→编码实现→测试验收；③ 提交完整交付物（需求分析、代码、设计文档、实验报告）；④ 课堂演示并答辩。
要求：项目能正常运行、核心功能无重大 bug；交付物齐全、符合规范；演示流畅、能答辩。
